# annotated product brief

> **Superseded.** Canonical product scope, non-goals, and roadmap live in [`PLAN.md`](./PLAN.md). Do not treat this file as source of truth.

## Positioning

Local-first AI meeting notepad. Audio stays on your machine unless you choose BYOK for text enhancement. No meeting bot. Live coaching during the call; clean notes after.

## Must-haves (v1)

- [ ] System / meeting audio capture (no bot participant)
- [ ] On-device transcription
- [ ] Local LLM summaries + action items (default)
- [ ] BYOK path (Claude / OpenAI) for notes only
- [ ] Per-meeting notes with searchable history
- [ ] Screen-share-safe coaching overlay (desktop)

## Inspired by

| From MeetMouse | From Granola |
| --- | --- |
| Local / private by default | Calendar-aware prep + memory |
| Live coaching mid-call | Polished notes & share flow |
| One-time / no-subscription ethos | Cross-platform ambition |

## Non-goals (for now)

- Cloud account required to take notes
- Bot that joins Zoom/Meet/Teams as a guest
- Shipping decompiled competitor code (clean-room only)
